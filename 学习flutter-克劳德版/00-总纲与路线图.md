# Flutter 学习总纲与路线图

> 面向读者：uniapp 经验丰富、Vue 精通、React 入门中，Dart 与 Flutter 零基础。
> 学完目标：能独立开发并上架一个完整的商业级 App。
> 节奏：每天 1.5–2 小时，约 6 周。

---

## 一、先建立正确的认知

### Flutter 和 uniapp 到底差在哪

这是你必须第一时间扭转的观念。

**uniapp 的运行方式**：你写 Vue，编译成小程序代码 / H5 / 或者塞进一个 WebView 里跑。屏幕上显示的东西，本质还是**浏览器渲染的 DOM**。所以你能用 CSS，能用 `class`，能审查元素。

**Flutter 的运行方式**：它自带一个渲染引擎（Skia / Impeller），屏幕上的**每一个像素都是 Flutter 自己画出来的**。没有 DOM，没有 WebView，没有浏览器。一个按钮的圆角、阴影、文字，全是它逐帧绘制的。

由此推导出四个直接后果：

| 后果 | 具体表现 |
|---|---|
| **没有 CSS** | 样式不是"选择器 + 属性"，而是"构造函数参数 + Widget 嵌套"。想加内边距，你得套一个 `Padding` Widget |
| **性能天花板高** | 60/120fps 原生级流畅，长列表、复杂动画不卡，这是 uniapp 的 WebView 方案做不到的 |
| **UI 高度一致** | 同一套代码在 iOS 和 Android 上像素级一致，不用处理浏览器兼容 |
| **包体积大、启动慢一点** | 因为要带引擎，空项目 apk 约 7–15MB |

### 三个平台的定位对比

| | uniapp | React Native | Flutter |
|---|---|---|---|
| 语言 | Vue / JS | React / JS | Dart |
| 渲染 | WebView / 小程序原生 | 映射到原生组件 | **自绘引擎** |
| 样式 | CSS | 类 CSS 的 StyleSheet | Widget 嵌套 + 参数 |
| 强项 | 多端（小程序！）、上手快 | 生态、原生外观 | 性能、UI 一致性、动画 |
| 弱项 | 性能、复杂动画 | 桥接性能、版本升级痛 | **不支持小程序**、Dart 需另学 |

> 重要提醒：**Flutter 不能编译小程序**（有 mpflutter 等第三方方案但不成熟）。如果你的业务离不开微信小程序，Flutter 是用来做原生 App 那一端的，不是 uniapp 的完全替代品。

## 二、你的经验能迁移多少

### ✅ 直接迁移（学起来会很快）

这些概念你脑子里已经有了，只需要换语法：

- 组件化拆分思维
- props 向下传、事件向上抛
- 生命周期概念（挂载/更新/销毁）
- 列表渲染、条件渲染
- 异步编程、Promise 思维
- 路由跳转与传参
- 为什么需要全局状态管理
- HTTP 请求封装、拦截器、Token 刷新

### ⚠️ 需要主动"忘掉"的负迁移（你最容易卡的地方）

这张表建议截图存手机里，前两周会反复用到。

| 你的 uniapp / Vue 习惯 | Flutter 的现实 |
|---|---|
| 写 CSS、class、样式继承 | **没有 CSS**。样式是参数，布局靠嵌套 Widget |
| `display:flex; flex:1` | `Row` / `Column` + `Expanded` |
| `position: absolute` | `Stack` + `Positioned` |
| `<div>` 万能容器 | `Container` 不完全等于 div，很多时候你要的是 `SizedBox` / `Padding` / `DecoratedBox` |
| `v-if` / `v-for` 模板指令 | 直接写 Dart 表达式：三元、`if`、`list.map().toList()`（**这点更像 React JSX，你学 React 是加分项**） |
| `rpx` 自动适配 | 逻辑像素 + `MediaQuery`，或引入 `flutter_screenutil` |
| `pages.json` 集中配置路由 | 路由写在代码里（`Navigator` 或 `go_router`） |
| `uni.request` / `uni.showToast` 全局 API 一把梭 | 什么都要去 pub.dev 找包，还可能要配原生权限 |
| JS 弱类型，随手 `res.data.list` | **强类型 + 空安全**，JSON 要转成模型类。这是最烦但收益最大的改变 |
| `this.xxx = 1` 自动更新视图 | 必须显式 `setState(() {})` 或用状态管理库 |
| F12 审查元素 | Flutter DevTools 的 Widget Inspector |
| scoped 样式隔离 | 不存在这个问题，样式本来就不会泄漏 |

### 🎁 你有的隐藏优势

1. **Vue 的响应式思维**：Provider / Riverpod 的用法和 Pinia 极其相似，第 4 周你会觉得很亲切。
2. **React 的 JSX 经验**：Flutter 的 `build` 方法本质就是"用代码描述 UI"，和 JSX 一个思路。你正在学 React，这块会平滑很多。
3. **uniapp 的 App 业务经验**：权限、上传、推送、支付、打包上架这些坑你都踩过，M12/M13 对你几乎是白送。

## 三、完整路线图（14 个模块 / 6 周）

**核心规则：每个模块必须交出"产出物"才算通过，"看完了"不算。**

## 四、M0：环境搭建

### 安装 Flutter SDK

**Windows**

```powershell
# 1. 下载 SDK（推荐用国内镜像，官网直下极慢）
#    https://mirrors.tuna.tsinghua.edu.cn/flutter/flutter_infra_release/releases/
# 2. 解压到无空格无中文路径，例如 D:\dev\flutter
# 3. 把 D:\dev\flutter\bin 加入系统环境变量 Path
# 4. 配置国内镜像（写进系统环境变量）
#    PUB_HOSTED_URL       = https://pub.flutter-io.cn
#    FLUTTER_STORAGE_BASE_URL = https://storage.flutter-io.cn
```

**macOS**

```bash
brew install --cask flutter
# 或手动解压后加入 PATH
echo 'export PATH="$PATH:$HOME/dev/flutter/bin"' >> ~/.zshrc
echo 'export PUB_HOSTED_URL=https://pub.flutter-io.cn' >> ~/.zshrc
echo 'export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn' >> ~/.zshrc
source ~/.zshrc
```

### 体检

```bash
flutter doctor -v
```

按提示逐条解决。常见项：

- **Android toolchain** → 装 Android Studio，SDK Manager 里装 Android SDK + Command-line Tools
- **Android licenses** → 跑 `flutter doctor --android-licenses`，一路 `y`
- **Xcode**（仅 macOS 做 iOS）→ App Store 装 Xcode，再 `sudo xcode-select --switch /Applications/Xcode.app`
- **Chrome** → 不装也行，只是不能跑 web 端

只要 Android toolchain 和至少一个设备是 ✓，就能开始了。

### 编辑器

**VS Code**（推荐，你应该已经在用）安装两个插件：
- `Flutter`（会自动带上 Dart 插件）
- `Awesome Flutter Snippets`（代码片段，敲 `statefulW` 自动生成模板）

建议再开一个设置，保存时自动格式化：

```json
// settings.json
{
  "[dart]": {
    "editor.formatOnSave": true,
    "editor.defaultFormatter": "Dart-Code.dart-code",
    "editor.rulers": [80]
  },
  "dart.previewFlutterUiGuides": true  // 显示 Widget 树引导线，新手非常有用
}
```

### 创建并运行第一个项目

```bash
flutter create my_app        # 项目名只能小写字母 + 下划线
cd my_app
flutter devices              # 看有哪些可用设备
flutter run                  # 运行
```

**真机调试**（比模拟器快，强烈推荐）：
- Android：手机开发者模式 → USB 调试 → 插上电脑 → `flutter run`
- iOS：需要 macOS + Xcode，用免费 Apple ID 也能真机调试，7 天有效期

跑起来之后，**在终端里试这三个键**：
- `r` → **Hot Reload 热重载**，保留状态刷新 UI，秒级（这是 Flutter 开发爽点，比 uniapp 编译快得多）
- `R` → **Hot Restart 热重启**，重置状态
- `q` → 退出

### 项目结构

```
my_app/
├── android/          # Android 原生工程（配权限、签名、包名）
├── ios/              # iOS 原生工程
├── lib/              # ★ 你 99% 的时间待在这里
│   └── main.dart     # 入口文件
├── assets/           # 图片、字体等静态资源（需自己建）
├── test/             # 单元测试
└── pubspec.yaml      # ★ 依赖 + 资源声明，相当于 package.json + 部分 pages.json
```

`pubspec.yaml` 是你第二常改的文件：

```yaml
name: my_app
description: 我的第一个 Flutter 应用

environment:
  sdk: '>=3.0.0 <4.0.0'

dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.6
  dio: ^5.4.0              # 加依赖就写在这里，相当于 npm install

dev_dependencies:
  flutter_lints: ^3.0.0

flutter:
  uses-material-design: true
  assets:                  # ★ 图片必须在这里声明，否则加载不到（新手高频坑）
    - assets/images/
  fonts:
    - family: MyFont
      fonts:
        - asset: assets/fonts/MyFont.ttf
```

> ⚠️ **YAML 缩进必须用空格，且层级严格**。改完执行 `flutter pub get`。

| 命令 | 作用 | uniapp 类比 |

## 五、学习方法与避坑建议

### 五条铁律

1. **每个模块必须有产出物。** 看视频点头没用，手要动。
2. **前两周不要抄 UI 模板。** 先把 Dart 和布局约束搞懂，否则你只是在复制粘贴魔法。
3. **报错先读完整堆栈。** Flutter 的报错信息写得非常详细，经常直接告诉你"你应该用 Expanded 包住它"。别看到红屏就慌。
4. **多用 Widget Inspector。** 布局出问题时打开 DevTools，能可视化看到每个 Widget 的实际尺寸和约束，比猜快十倍。
5. **善用官方文档的 Widget 目录。** flutter.dev 上每个 Widget 都有配图和 demo，比搜中文博客靠谱。

### 心态提示

第 2 周布局那块，你大概率会经历一个阶段："为什么加个居中要套三层 Widget？"——这是所有从 CSS 转过来的人的必经之路。撑过去之后，你会发现 Widget 嵌套的可组合性其实比 CSS 更可控（没有样式污染、没有继承地狱、没有 `!important`）。

另一个心理落差：**Flutter 代码看起来嵌套很深、很啰嗦**。这是真的。缓解方法是把 UI 拆成小 Widget（就像你拆 Vue 组件一样），配合编辑器的 Widget 引导线。不要试图在一个 `build` 里写完整个页面。

### 资源清单

**必备**
- 官方文档 https://docs.flutter.dev —— 质量极高，Widget catalog 部分尤其
- pub.dev —— Flutter 的 npm，找包看这里，重点看 Likes / Pub Points / 最后更新时间
- Flutter 中文网 https://flutter.cn —— 官方中文镜像

**进阶**
- Flutter DevTools —— 调试布局、查性能、看内存，`flutter run` 后终端会给链接
- Widget of the Week（YouTube / B站有搬运）—— 每集 2 分钟讲一个组件
- 《Flutter实战·第二版》 book.flutterchina.club —— 免费中文电子书，讲原理很透

**代码参考**
- flutter/samples GitHub 仓库 —— 官方示例
- Flutter Gallery App —— 装一个在手机上，看官方组件的实际效果
