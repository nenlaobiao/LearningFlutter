# M3 布局体系

## 3.1 告别 CSS：世界观切换

### 一个例子看清差异

需求：一个白底、圆角、带阴影、内边距 16、居中显示红色文字的盒子。

**你熟悉的写法：**

```html
<view class="box">Hello</view>

<style>
.box {
  background: #fff;
  border-radius: 8px;
  box-shadow: 0 2px 4px rgba(0,0,0,.1);
  padding: 16px;
  display: flex;
  justify-content: center;
  align-items: center;
  color: red;
}
</style>
```

**Flutter：**

```dart
Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
    boxShadow: const [
      BoxShadow(color: Colors.black12, blurRadius: 4, offset: Offset(0, 2)),
    ],
  ),
  alignment: Alignment.center,
  child: const Text('Hello', style: TextStyle(color: Colors.red)),
)
```

### 三条必须内化的原则

**1. 样式是参数，不是声明**

CSS 里你给元素"贴"样式；Flutter 里样式是构造函数的参数，直接写在组件上。没有选择器、没有 class、没有样式继承（除了 Theme），因此也没有样式冲突和优先级问题。

**2. 布局能力靠 Widget 嵌套实现**

CSS 里一个元素能同时拥有 padding、margin、居中、旋转。Flutter 里这些是**不同的 Widget**：

```dart
// 一个元素想同时有 内边距 + 居中 + 圆角
Center(                              // 居中
  child: ClipRRect(                  // 圆角裁剪
    borderRadius: BorderRadius.circular(8),
    child: Padding(                  // 内边距
      padding: const EdgeInsets.all(16),
      child: Text('hi'),
    ),
  ),
)
```

**这就是 Flutter 代码嵌套深的根本原因。** 好处是每个 Widget 职责单一、可自由组合；代价是啰嗦。

`Container` 是个"全家桶"，把常用的几个能力打包在一起，所以入门先用它没问题。

**3. 没有全局样式表，复用靠抽 Widget 和 Theme**

```dart
// 复用样式 → 抽成常量
class AppStyles {
  static const title = TextStyle(fontSize: 18, fontWeight: FontWeight.bold);
  static final cardDecoration = BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
  );
}

// 复用结构 → 抽成 Widget
class AppCard extends StatelessWidget {
  final Widget child;
  const AppCard({super.key, required this.child});
  @override
  Widget build(BuildContext context) => Container(
    decoration: AppStyles.cardDecoration,
    padding: const EdgeInsets.all(12),
    child: child,
  );
}
```

## 3.2 布局的核心：约束模型

**这一节是整个 Flutter 布局的地基，看不懂就多读两遍。**

Flutter 布局遵循一句话：

> **约束向下传递，尺寸向上返回，位置由父级决定。**
> (Constraints go down. Sizes go up. Parent sets position.)

### 具体过程

1. 父 Widget 告诉子 Widget："你的宽度必须在 0–300 之间，高度必须在 0–500 之间"（这就是**约束**，`BoxConstraints`）。
2. 子 Widget 在这个范围内决定自己的尺寸，告诉父级："我要 100×50"。
3. 父 Widget 决定把它放在哪个位置。

### 由此产生的三个反直觉现象

**现象一：子 Widget 不能自己决定位置**

```dart
// ❌ 没有 "position: absolute; top: 10px" 这种东西
// ✅ 位置由父级控制
Align(alignment: Alignment.topRight, child: Text('右上'))
Stack(children: [Positioned(top: 10, right: 10, child: Text('右上'))])
```

**现象二：Container 有时撑满，有时收缩**

```dart
// 场景 A：Container 没有子元素 → 撑满父级可用空间
Container(color: Colors.red)                    // 铺满整屏

// 场景 B：Container 有子元素 → 收缩到子元素大小
Container(color: Colors.red, child: Text('hi')) // 只有文字那么大
```

原因就是约束模型：没有 child 时它取最大约束，有 child 时它取子元素尺寸。想强制撑满：

```dart
Container(
  width: double.infinity,       // 或者用 SizedBox.expand()
  color: Colors.red,
  child: const Text('hi'),
)
```

**现象三：约束会"穿透"**

```dart
Center(
  child: Container(
    width: 500,             // 屏幕只有 375 宽
    color: Colors.red,
  ),
)
// 结果：宽度是 375，不是 500
// 因为 Center 给的约束最大就是屏幕宽，Container 无法突破
```

想突破父级约束要用 `UnconstrainedBox` 或 `OverflowBox`，但这属于进阶，日常很少用。

### 调试工具：Widget Inspector

布局出问题时**不要靠猜**。运行 `flutter run` 后：

1. 终端会输出一个 DevTools 链接，或在 VS Code 里按 `Ctrl+Shift+P` → `Flutter: Open DevTools`
2. 打开 **Widget Inspector**
3. 点击界面上任意元素，右侧会显示它的实际尺寸和收到的约束

还有个更快的：在 `main()` 里开启布局线框图。

```dart
import 'package:flutter/rendering.dart';

void main() {
  debugPaintSizeEnabled = true;    // 显示所有 Widget 的边界线
  runApp(const MyApp());
}
```

或者直接在 DevTools 工具栏点 "Show Guidelines"。**这个功能能解决你 80% 的布局困惑**，第一天就打开它。

## 3.3 Container 全解

`Container` 是入门期最常用的容器，把它当成"能配样式的 div"，但要清楚它内部其实是多个 Widget 的组合。

```dart
Container(
  // 尺寸
  width: 200,
  height: 100,
  constraints: const BoxConstraints(minHeight: 50, maxWidth: 300),
  
  // 间距
  margin: const EdgeInsets.only(top: 10, bottom: 10),
  padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 8),
  
  // 对齐（有了它，child 才会在容器内定位）
  alignment: Alignment.center,
  
  // 背景与装饰 —— 注意 color 和 decoration 不能同时用！
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
    border: Border.all(color: Colors.grey.shade300, width: 1),
    boxShadow: const [
      BoxShadow(color: Colors.black12, blurRadius: 6, offset: Offset(0, 2)),
    ],
    gradient: const LinearGradient(colors: [Colors.blue, Colors.purple]),
  ),
  
  // 变换
  transform: Matrix4.rotationZ(0.1),
  
  child: const Text('内容'),
)
```

> ⚠️ **高频报错**：`Cannot provide both a color and a decoration`。用了 `decoration` 就把 `color` 挪进 `BoxDecoration` 里。

### EdgeInsets 的四种写法

```dart
EdgeInsets.all(16)                                    // 四边都是 16
EdgeInsets.symmetric(horizontal: 16, vertical: 8)     // 左右 16，上下 8
EdgeInsets.only(left: 16, top: 8)                     // 单独指定
EdgeInsets.fromLTRB(16, 8, 16, 8)                     // 左上右下
```

### 什么时候不该用 Container

`Container` 功能多意味着开销大。只用一个功能时，用专门的 Widget 更好：

| 只想要 | 用这个，而不是 Container |
|---|---|
| 内边距 | `Padding` |
| 固定尺寸 / 间隔 | `SizedBox` |
| 居中 | `Center` |
| 对齐 | `Align` |
| 纯背景色 | `ColoredBox` |
| 圆角裁剪 | `ClipRRect` |
| 装饰 | `DecoratedBox` |

```dart
// ⚠️ 能用但重
Container(padding: const EdgeInsets.all(16), child: child)
// ✅ 更轻，还能加 const
const Padding(padding: EdgeInsets.all(16), child: child)
```

## 3.4 Row 与 Column（核心）

这两个就是 Flutter 版的 flex 布局，**你 90% 的界面靠它们**。

- `Row` = `display:flex; flex-direction: row`（横向排列）
- `Column` = `display:flex; flex-direction: column`（纵向排列）

### 主轴与交叉轴

这是最容易搞混的地方，记住一句话：**主轴就是排列方向**。

| | 主轴 (Main Axis) | 交叉轴 (Cross Axis) |
|---|---|---|
| `Row` | 水平 → | 垂直 ↕ |
| `Column` | 垂直 ↓ | 水平 ↔ |

```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,   // 水平方向如何分布
  crossAxisAlignment: CrossAxisAlignment.center,       // 垂直方向如何对齐
  children: [
    Text('左'),
    Text('中'),
    Text('右'),
  ],
)
```

### 对照 CSS flex

| CSS | Flutter |
|---|---|
| `justify-content: flex-start` | `MainAxisAlignment.start`（默认） |
| `justify-content: center` | `MainAxisAlignment.center` |
| `justify-content: flex-end` | `MainAxisAlignment.end` |
| `justify-content: space-between` | `MainAxisAlignment.spaceBetween` |
| `justify-content: space-around` | `MainAxisAlignment.spaceAround` |
| `justify-content: space-evenly` | `MainAxisAlignment.spaceEvenly` |
| `align-items: flex-start` | `CrossAxisAlignment.start` |
| `align-items: center` | `CrossAxisAlignment.center`（默认） |
| `align-items: stretch` | `CrossAxisAlignment.stretch` |
| `align-items: baseline` | `CrossAxisAlignment.baseline` |
| `flex-wrap: wrap` | **换成 `Wrap` 组件**（Row 不支持换行！） |
| `flex: 1` | `Expanded` |
| `gap: 10px` | **没有**，手动插 `SizedBox`（或用 `Wrap` 的 spacing） |

### mainAxisSize：一个高频坑

```dart
// 默认 max：Column 会在垂直方向撑满整个可用高度
Column(
  children: [Text('a'), Text('b')],
)

// min：只占内容高度（相当于 CSS 里的 fit-content）
Column(
  mainAxisSize: MainAxisSize.min,
  children: [Text('a'), Text('b')],
)
```

放在 Dialog、Card 里的 Column，**忘了写 `mainAxisSize: MainAxisSize.min` 会导致弹窗撑到全屏**，这是新手常见问题。

### 交叉轴对齐的实际效果

```dart
Column(
  crossAxisAlignment: CrossAxisAlignment.start,   // ★ 文字左对齐
  children: [
    Text('标题'),
    Text('副标题'),
  ],
)
```

> Column 默认 `crossAxisAlignment: center`，所以你写的文字默认是**居中**的。想左对齐必须显式写 `start` —— 这个和 Web 的默认行为相反，会坑你很多次。

### Wrap：会换行的 Row

```dart
Wrap(
  spacing: 8,           // 主轴间距
  runSpacing: 8,        // 换行后的行间距
  alignment: WrapAlignment.start,
  children: tags.map((t) => Chip(label: Text(t))).toList(),
)
```

标签云、筛选条件这类场景用 `Wrap`，`Row` 放不下会直接报溢出错误。

## 3.5 Expanded / Flexible / Spacer

**`Expanded` 就是 `flex: 1`。**

```dart
Row(
  children: [
    Container(width: 50, color: Colors.red),
    Expanded(                                    // 占满剩余空间
      child: Container(color: Colors.green),
    ),
    Container(width: 50, color: Colors.blue),
  ],
)
```

### 按比例分配

```dart
Row(
  children: [
    Expanded(flex: 1, child: Container(color: Colors.red)),     // 占 1/3
    Expanded(flex: 2, child: Container(color: Colors.blue)),    // 占 2/3
  ],
)
```

### Expanded vs Flexible

| | 行为 | CSS 类比 |
|---|---|---|
| `Expanded` | **强制**占满分配到的空间 | `flex: 1 1 0` |
| `Flexible` | **最多**占那么多，内容小就收缩 | `flex: 0 1 auto` |

```dart
// 文字短时，Expanded 的背景色会拉满，Flexible 只包住文字
Row(children: [
  Expanded(child: Container(color: Colors.red, child: Text('短'))),
])
```

日常 90% 的情况用 `Expanded` 就对了。

### Spacer：弹性空白

```dart
Row(
  children: [
    Text('左'),
    Spacer(),           // 把剩下的空间全占了，等价于 Expanded(child: SizedBox())
    Text('右'),
  ],
)
// 效果等同于 mainAxisAlignment: spaceBetween
```

### 最经典的报错：文字溢出

```dart
// ❌ 文字很长时报 RenderFlex overflowed
Row(children: [
  Icon(Icons.person),
  Text('这是一段非常非常非常非常非常长的用户名字'),
])

// ✅ 用 Expanded 约束宽度
Row(children: [
  const Icon(Icons.person),
  Expanded(
    child: Text(
      '这是一段非常非常非常非常非常长的用户名字',
      overflow: TextOverflow.ellipsis,     // 超出显示 ...
      maxLines: 1,
    ),
  ),
])
```

**记住这个组合**：`Row` + 长文本 = 必须 `Expanded` + `overflow`。

## 3.6 Stack 与 Positioned（定位）

`Stack` = `position: relative` 的父容器，`Positioned` = `position: absolute` 的子元素。

```dart
Stack(
  alignment: Alignment.center,       // 未定位子元素的对齐方式
  children: [
    // 第一个在最底层
    Image.network('https://xxx.jpg', width: double.infinity, height: 200, fit: BoxFit.cover),
    
    // 定位元素
    Positioned(
      left: 12,
      bottom: 12,
      child: Text('图片标题', style: TextStyle(color: Colors.white)),
    ),
    
    Positioned(
      right: 8,
      top: 8,
      child: Container(
        padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
        decoration: BoxDecoration(
          color: Colors.red,
          borderRadius: BorderRadius.circular(10),
        ),
        child: const Text('HOT', style: TextStyle(color: Colors.white, fontSize: 10)),
      ),
    ),
  ],
)
```

**典型用途**：角标、蒙层、悬浮按钮、图片上叠文字、自定义指示器。

`Positioned.fill()` 相当于 `top:0;right:0;bottom:0;left:0`，常用于加渐变蒙层：

```dart
Stack(children: [
  Image.network(url),
  Positioned.fill(
    child: DecoratedBox(
      decoration: BoxDecoration(
        gradient: LinearGradient(
          begin: Alignment.topCenter,
          end: Alignment.bottomCenter,
          colors: [Colors.transparent, Colors.black54],
        ),
      ),
    ),
  ),
])
```

## 3.7 间距与对齐的正确姿势

### 间距：SizedBox 是主力

Flutter 的 Row/Column **没有 `gap` 属性**（Flutter 3.27+ 才给 Row/Column 加了 `spacing`，老版本没有）。标准做法：

```dart
Column(
  children: [
    Text('a'),
    const SizedBox(height: 12),      // ★ 垂直间距
    Text('b'),
    const SizedBox(height: 12),
    Text('c'),
  ],
)

Row(
  children: [
    Text('a'),
    const SizedBox(width: 8),        // ★ 水平间距
    Text('b'),
  ],
)
```

`SizedBox` 也用来指定固定尺寸：

```dart
const SizedBox(width: 100, height: 50, child: ...)
const SizedBox.shrink()              // 0×0，相当于"什么都不渲染"
const SizedBox.expand()              // 撑满
```

> **小技巧**：列表项之间统一加间距，可以用 `separated` 系列或者写个 extension，别一个个手写。

### 对齐

```dart
Center(child: child)                                        // 居中

Align(alignment: Alignment.topRight, child: child)          // 指定位置
// Alignment 可选：topLeft topCenter topRight
//                centerLeft center centerRight
//                bottomLeft bottomCenter bottomRight
Align(alignment: const Alignment(0.5, -0.3), child: child)  // -1~1 的坐标系
```

### 常见组合速查

```dart
// 水平垂直都居中
Center(child: Text('居中'))

// 靠右
Align(alignment: Alignment.centerRight, child: Text('右'))

// 撑满宽度的按钮
SizedBox(width: double.infinity, child: ElevatedButton(...))

// 两端对齐
Row(mainAxisAlignment: MainAxisAlignment.spaceBetween, children: [左, 右])

// 左图标 + 右文字（文字可能很长）
Row(children: [Icon(...), const SizedBox(width: 8), Expanded(child: Text(...))])
```

## 3.8 滚动与溢出

### SingleChildScrollView

内容超一屏就要能滚，否则报黄黑条溢出错误。

```dart
SingleChildScrollView(
  padding: const EdgeInsets.all(16),
  child: Column(
    children: [ /* 很多内容 */ ],
  ),
)
```

> ⚠️ **绝对不要在 `SingleChildScrollView` 里放不限高的 `ListView`**，会报 unbounded height 错误。列表用 `ListView.builder` 本身就能滚（第 3 周细讲）。

### 安全区

刘海屏、底部手势条要避让：

```dart
SafeArea(
  child: YourContent(),
)
```

`Scaffold` 的 `body` 默认不包含 SafeArea（AppBar 有），全屏页面记得加。

### 键盘遮挡输入框

```dart
Scaffold(
  resizeToAvoidBottomInset: true,     // 默认 true，键盘弹出时压缩 body
  body: SingleChildScrollView(         // 配合滚动，输入框才能被顶上去
    child: Column(children: [...]),
  ),
)
```

## 3.9 CSS 到 Flutter 完整对照表

打印出来贴显示器上，前两周会天天查。

### 盒模型

| CSS | Flutter |
|---|---|
| `width` / `height` | `SizedBox(width:, height:)` 或 `Container(width:, height:)` |
| `width: 100%` | `double.infinity` 或 `Expanded` |
| `min-width` / `max-width` | `ConstrainedBox(constraints: BoxConstraints(...))` |
| `padding` | `Padding(padding: EdgeInsets...)` |
| `margin` | `Container(margin:)` 或外面套 `Padding` |
| `background-color` | `Container(color:)` / `ColoredBox` |
| `border` | `BoxDecoration(border: Border.all(...))` |
| `border-radius` | `BoxDecoration(borderRadius:)` 或 `ClipRRect` |
| `box-shadow` | `BoxDecoration(boxShadow: [BoxShadow(...)])` |
| `background: linear-gradient` | `BoxDecoration(gradient: LinearGradient(...))` |
| `opacity` | `Opacity(opacity: 0.5, child:)` |
| `overflow: hidden` | `ClipRect` / `ClipRRect` |
| `transform` | `Transform.rotate/scale/translate` |
| `z-index` | `Stack` 中的顺序（后面的在上层） |
| `cursor: pointer` | `MouseRegion` / `InkWell` 自带 |

### Flex

| CSS | Flutter |
|---|---|
| `display: flex` | `Row` / `Column` |
| `flex-direction: row` | `Row` |
| `flex-direction: column` | `Column` |
| `flex-direction: row-reverse` | `Row(textDirection: TextDirection.rtl)` |
| `justify-content` | `mainAxisAlignment` |
| `align-items` | `crossAxisAlignment` |
| `flex: 1` | `Expanded` |
| `flex-wrap: wrap` | `Wrap` |
| `gap` | 插 `SizedBox`（或新版 `spacing`） |
| `align-self` | `Align` 包住那个子元素 |

### 定位

| CSS | Flutter |
|---|---|
| `position: relative` (父) | `Stack` |
| `position: absolute` | `Positioned` |
| `top/right/bottom/left` | `Positioned(top:, right:, ...)` |
| `position: fixed` | `Stack` 放在页面最外层 |
| `inset: 0` | `Positioned.fill()` |

### 文字

| CSS | Flutter |
|---|---|
| `font-size` | `TextStyle(fontSize:)` |
| `font-weight: bold` | `TextStyle(fontWeight: FontWeight.bold)` |
| `color` | `TextStyle(color:)` |
| `text-align` | `Text(textAlign:)` |
| `line-height: 1.5` | `TextStyle(height: 1.5)` |
| `letter-spacing` | `TextStyle(letterSpacing:)` |
| `text-decoration` | `TextStyle(decoration: TextDecoration.lineThrough)` |
| `text-overflow: ellipsis` | `Text(overflow: TextOverflow.ellipsis, maxLines: 1)` |
| `-webkit-line-clamp: 2` | `Text(maxLines: 2, overflow: TextOverflow.ellipsis)` |

### 单位

| uniapp | Flutter |
|---|---|
| `px` | 逻辑像素（直接写数字，无单位） |
| `rpx`（750 设计稿自适应） | 无内置方案。用 `MediaQuery.of(context).size.width` 换算，或引入 `flutter_screenutil` |
| `vw` / `vh` | `MediaQuery.of(context).size.width * 0.5` |
| `%` | `FractionallySizedBox(widthFactor: 0.5)` 或 `Expanded` |

关于适配，简单说：**Flutter 的逻辑像素已经做了 DPI 缩放**，在大多数手机上直接写数字视觉差异不大，不像 Web 那么必须用 rpx。等真遇到还原度问题再上 `flutter_screenutil`，别一上来就引入。

## 3.10 布局报错急救手册

这一节请重点看，能省你几十小时。

### ① RenderFlex overflowed by XX pixels

**黄黑条纹警告。** 内容超出了 Row/Column 的可用空间。

```dart
// 常见原因 1：Row 里的文字太长
Row(children: [Icon(...), Text('超长文字...')])
// → 用 Expanded 包住 Text，加 overflow: TextOverflow.ellipsis

// 常见原因 2：Column 内容超过一屏
Column(children: [很多东西])
// → 外面套 SingleChildScrollView

// 常见原因 3：键盘弹出后空间变小
// → Scaffold 加 resizeToAvoidBottomInset，body 套 SingleChildScrollView
```

### ② Vertical viewport was given unbounded height

**在没有高度限制的地方放了可滚动组件。**

```dart
// ❌ Column 内部高度不确定，ListView 也想要无限高
Column(children: [ListView(...)])

// ✅ 方案 1：用 Expanded 给它一个确定高度
Column(children: [Expanded(child: ListView(...))])

// ✅ 方案 2：让 ListView 收缩到内容高度（列表短时用）
Column(children: [
  ListView(
    shrinkWrap: true,
    physics: const NeverScrollableScrollPhysics(),   // 禁用自身滚动
    children: [...],
  ),
])

// ✅ 方案 3：给固定高度
SizedBox(height: 200, child: ListView(...))
```

> `shrinkWrap: true` 会让 ListView 失去懒加载优化，**只在列表很短时用**。长列表必须用方案 1。

### ③ Incorrect use of ParentDataWidget

`Expanded` / `Flexible` 只能直接放在 `Row` / `Column` / `Flex` 里，`Positioned` 只能直接放在 `Stack` 里。

```dart
// ❌ Expanded 的直接父级是 Container
Container(child: Expanded(child: Text('x')))

// ✅
Row(children: [Expanded(child: Text('x'))])
```

### ④ Cannot provide both a color and a decoration

```dart
// ❌
Container(color: Colors.red, decoration: BoxDecoration(borderRadius: ...))
// ✅
Container(decoration: BoxDecoration(color: Colors.red, borderRadius: ...))
```

### ⑤ 圆角不生效 / 图片没被裁剪

`BoxDecoration` 的圆角对子元素不裁剪，图片会溢出圆角。

```dart
// ✅ 用 ClipRRect 真正裁剪
ClipRRect(
  borderRadius: BorderRadius.circular(8),
  child: Image.network(url, fit: BoxFit.cover),
)
```

### ⑥ 设了 width/height 不生效

被父级约束压制了。检查父级是不是 `Row`（会强制子元素的高度）或者外面套了 `Expanded`。用 Widget Inspector 看实际约束。

### ⑦ 点击没反应

`Container` 没有背景色时，透明区域不响应点击：

```dart
// ❌ 透明区域点不到
GestureDetector(onTap: ..., child: Container(width: 100, height: 100))

// ✅
GestureDetector(
  behavior: HitTestBehavior.opaque,      // ★ 加这行
  onTap: ...,
  child: Container(width: 100, height: 100),
)
```

## 4.7 Form 表单校验

```dart
class _LoginPageState extends State<LoginPage> {
  final _formKey = GlobalKey<FormState>();
  String _phone = '';
  String _password = '';

  void _submit() {
    if (_formKey.currentState!.validate()) {     // 触发所有校验
      _formKey.currentState!.save();              // 触发所有 onSaved
      print('提交 $_phone $_password');
    }
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: _formKey,
      child: Column(
        children: [
          TextFormField(
            decoration: const InputDecoration(labelText: '手机号'),
            keyboardType: TextInputType.phone,
            validator: (value) {
              if (value == null || value.isEmpty) return '请输入手机号';
              if (value.length != 11) return '手机号格式不正确';
              return null;                        // ★ 返回 null 表示校验通过
            },
            onSaved: (v) => _phone = v ?? '',
          ),
          const SizedBox(height: 16),
          TextFormField(
            decoration: const InputDecoration(labelText: '密码'),
            obscureText: true,
            validator: (v) => (v?.length ?? 0) < 6 ? '密码至少 6 位' : null,
            onSaved: (v) => _password = v ?? '',
          ),
          const SizedBox(height: 24),
          SizedBox(
            width: double.infinity,
            child: ElevatedButton(onPressed: _submit, child: const Text('登录')),
          ),
        ],
      ),
    );
  }
}
```

注意用的是 `TextFormField` 不是 `TextField`。校验函数**返回 null 表示通过**，返回字符串则显示为错误提示 —— 这个约定第一次见会觉得反直觉。

## 4.9 反馈类：Toast / Dialog / BottomSheet

这块和 uniapp 差异较大，`uni.showToast` 这种全局 API 在 Flutter 里需要 `context`。

### SnackBar（≈ uni.showToast）

```dart
ScaffoldMessenger.of(context).showSnackBar(
  const SnackBar(content: Text('保存成功')),
);
```

> Flutter 原生的 SnackBar 是从底部弹出的条，和 uniapp 的居中 Toast 观感不同。想要类似效果，社区包 `fluttertoast` 或 `bot_toast` 更贴近，且**不需要 context**，用起来更接近你的习惯。

### AlertDialog（≈ uni.showModal）

```dart
final result = await showDialog<bool>(
  context: context,
  builder: (context) => AlertDialog(
    title: const Text('提示'),
    content: const Text('确定要删除吗？'),
    actions: [
      TextButton(
        onPressed: () => Navigator.pop(context, false),
        child: const Text('取消'),
      ),
      TextButton(
        onPressed: () => Navigator.pop(context, true),
        child: const Text('确定'),
      ),
    ],
  ),
);

if (result == true) {
  // 用户点了确定
}
```

注意 `showDialog` 返回 `Future`，用 `await` 拿结果，`Navigator.pop(context, 值)` 把结果传回来。这个模式比 uniapp 的 `success` 回调清爽。

### BottomSheet（≈ uni.showActionSheet）

```dart
showModalBottomSheet(

  shape: const RoundedRectangleBorder(

  ),
  builder: (context) => Column(
    mainAxisSize: MainAxisSize.min,     // ★ 别忘了，否则撑满全屏
    children: [
      ListTile(title: const Text('拍照'), onTap: () => Navigator.pop(context, 'camera')),
      ListTile(title: const Text('从相册选择'), onTap: () => Navigator.pop(context, 'gallery')),

```
